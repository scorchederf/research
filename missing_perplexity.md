| fullpath | reason to include |
|---|---|
|HKCU\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\RunOnce|One-time user persistence that runs once at next logon then self-deletes. Complements the Run key already listed, and attackers use it for payloads that only need to execute a single time.|
|HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\RunOnce|Machine-wide version of the above. Runs once at the next logon for any user with sufficient privilege, then removes itself, so it can be missed if you only review Run keys.|
|HKLM\\SOFTWARE\\WOW6432Node\\Microsoft\\Windows\\CurrentVersion\\Run|The 32-bit Run key on 64-bit Windows. Analysts and even some tools overlook WOW6432Node, so malware placed here survives sloppy persistence reviews.|
|HKCU\\Software\\Microsoft\\Windows NT\\CurrentVersion\\Winlogon|Per-user Winlogon key. Setting the Shell value here overrides explorer.exe for that user at logon, giving a persistence trick most analysts never check since they only review the HKLM Winlogon key.|
|HKLM\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\ProfileList|Maps every user SID to their profile path with timestamps via the profile hive. Fast way to enumerate accounts (including deleted ones) and spot unexpected profiles on a host.|
|HKLM\\SYSTEM\\CurrentControlSet\\Control\\Session Manager\\AppCertDlls|DLLs listed here are loaded into every process created on the system. Extremely powerful SYSTEM-level persistence that rarely appears on standard checklists.|
|HKLM\\SYSTEM\\CurrentControlSet\\Services\\WinSock2\\Parameters\\NameSpace_Catalog5\\Catalog_Entries64|Winsock namespace provider registrations. A malicious provider DLL is loaded into any process using Winsock, giving stealthy userland persistence inside browsers and network apps.|
|HKLM\\SYSTEM\\CurrentControlSet\\Control\\Class\\{4d36e96b-e325-11ce-bfc1-08002be10318}|Keyboard device class key. An attacker adding an UpperFilters driver value here installs a keylogger-grade filter driver, so unexpected UpperFilters entries are high signal.|
|HKLM\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Accessibility|Assistive Technology configuration. Custom AT registrations can be triggered at the logon screen as SYSTEM, a modernised variant of the classic sethc/utilman swap.|
|HKLM\\SYSTEM\\CurrentControlSet\\Services\\Tcpip\\Parameters\\Interfaces|Per-interface DNS server configuration. An attacker changing DNS servers here redirects name resolution network-wide for that host, enabling interception and phishing.|
|C:\\Users\\<username>\\AppData\\Local\\Google\\Chrome\\User Data\\Default|Chrome profile with history, cookies and Login Data. The list covers Edge but Chrome dominates most fleets, and it is the number one infostealer target for session cookie theft.|
|C:\\Program Files\\Windows Defender Advanced Threat Protection\\MsSense.exe|The MDE sensor binary itself. The folder is listed but the specific service binary matters: killed or tampered MsSense means your EDR is blind, so alert on service stop or file changes.|
|C:\\Windows\\System32\\spool\\SERVERS|Print server connection metadata. Rogue entries here tie into malicious print server and driver injection attacks against the spooler.|
|C:\\PerfLogs|World-writable folder on most builds that is nearly always empty. Its obscurity makes it a popular attacker staging directory and it features in UAC bypass/DLL search order tricks.|
|C:\\Windows\\tracing|RAS and network tracing output when tracing is enabled. These logs can capture authentication detail and are often forgotten during evidence review.|
