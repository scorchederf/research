**fullpath**:C:\ProgramData\Microsoft\Windows Defender

# description

Data folder of Microsoft Defender Antivirus, registered as `ProductAppDataPath` under `HKLM\SOFTWARE\Microsoft\Windows Defender`. It holds the updatable antimalware platform versions (where the latest `MpCmdRun.exe` lives) and the support/diagnostic output generated by `MpCmdRun.exe`.

## simple description

> ### 2026-11-21 Claude said
> This is where Microsoft Defender Antivirus keeps its working data: the current platform binaries, signature definitions, scan history, quarantine and support logs. It is protected by Defender's tamper protection and normal users can't change it. Defender updates drop new platform versions into the Platform subfolder.
>
> **SOC NOTE**: Rich forensic source: `Scans\History` (detections), `Quarantine` (encrypted copies of detected malware), `Support\MPLog-*.log` (scan, exclusion and process activity; useful even for files later deleted). Attackers target it to tamper with Defender (T1562.001) or abuse symlinks; also check exclusions in the registry.
>

# purpose

Stores Defender Antivirus application data. The latest `MpCmdRun.exe` is in `%ProgramData%\Microsoft\Windows Defender\Platform\<antimalware platform version>` (recommended over `%ProgramFiles%\Windows Defender`). `MpCmdRun.exe -GetFiles` generates the diagnostic package at `C:\ProgramData\Microsoft\Windows Defender\Support\MpSupportFiles.cab`, containing Antimalware Service trace files, Windows Update history, Antimalware Service events, relevant registry locations, the MpCmdRun log and the signature update helper log.

# common files found

| path | description |
| --- | --- |
| `Platform\<antimalware platform version>\` | Updated Defender platform binaries, including `MpCmdRun.exe`. |
| `Support\MpSupportFiles.cab` | Diagnostic package created by `MpCmdRun.exe -GetFiles`. |
