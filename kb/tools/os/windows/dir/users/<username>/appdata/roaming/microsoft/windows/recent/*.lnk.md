**fullpath**:C:\Users\<username>\AppData\Roaming\Microsoft\Windows\Recent\*.lnk

# description

Shortcut (.lnk) files in the per-user Recent folder, the file-system directory identified by `CSIDL_RECENT` / `FOLDERID_Recent` whose typical path is `C:\Users\<username>\AppData\Roaming\Microsoft\Windows\Recent`. The Windows Shell creates these shortcuts through `SHAddToRecentDocs`; Windows Installer exposes the folder as the `RecentFolder` property.

## simple description

> ### 2026-11-21 Claude said
> Every time a user opens a document through Explorer or a standard Open/Save dialog, Windows drops a small shortcut file (.lnk) for it into the user's Recent folder. These shortcuts feed the "Recent items" lists in Start and in Jump Lists. Each .lnk records the target path and, inside the shortcut, timestamps, volume serial number and sometimes the machine name/MAC of where the target lived. The shortcut stays even after the original file is deleted or the USB stick is unplugged.
>
> **SOC NOTE**: High-value user-activity artifact (file and folder access, including from removable media and network shares). The .lnk creation/modification times approximate first/last open of the target; embedded volume and network data can prove a file came from a particular USB device or UNC share. Useful when investigating data exfiltration, insider activity or the opening of a malicious document (T1204.002). Attackers may clear it (T1070.004) or disable recent-doc tracking. Parse with LECmd or similar; correlate with AutomaticDestinations/CustomDestinations Jump Lists and ShellBags.
>

# purpose

The Recent folder "contains shortcuts to the user's most recently used documents" (CSIDL_RECENT). When `SHAddToRecentDocs` is called, the Shell updates the application's Jump List Recent/Frequent lists and adds a shortcut to the Recent folder, which is reflected in the **Recent Items** menu (Windows Vista and later). The Shell calls this function on behalf of the application when the user opens an item through Windows Explorer or uses the common file dialog to open, save, or create a file. Executable (.exe) files are filtered from the recent documents list, items represented by an `IShellLink` are not added to the Recent folder, and folders appear only in the Explorer Jump List.
