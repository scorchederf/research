## simple description

> ### 2026-11-21 Claude said
> This folder holds per-user configuration and logs for AnyDesk, a third-party remote desktop application (not a Microsoft product). It is created when AnyDesk runs in portable or installed mode for that user. Files here include the user's settings, connection trace log and the remote-ID configuration.
>
> **SOC NOTE**: AnyDesk is widely abused by ransomware groups and tech-support scammers for persistent remote access (MITRE ATT&CK T1219 Remote Access Software). Key artifacts: ad.trace (connection log with remote IDs and IPs), connection_trace.txt (incoming sessions), user.conf and system.conf. Check for AnyDesk on systems where it isn't approved and review the trace files for session times and file transfers.
