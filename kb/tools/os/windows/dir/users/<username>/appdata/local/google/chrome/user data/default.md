## simple description

> ### 2026-11-21 Claude said
> This folder is the default Google Chrome browser profile for a Windows user. It stores browsing history, cookies, saved logins, bookmarks, extensions, cache and settings. Each additional Chrome profile gets its own sibling folder (Profile 1, Profile 2, ...).
>
> **SOC NOTE**: High forensic value: History (SQLite: URLs, downloads), Login Data and Cookies (DPAPI/app-bound encrypted secrets), Web Data, Extensions, Preferences. Infostealers target these files (T1555.003, T1539); malicious extensions are a persistence path (T1176). Unexpected processes reading Login Data/Cookies are a strong signal.
