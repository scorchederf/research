## simple description

> ### 2026-11-21 Claude said
> This folder holds the Mozilla Firefox user profiles for one Windows user, each in a randomly named subfolder like `xxxxxxxx.default-release`. A profile contains browsing history, bookmarks, cookies, saved logins, extensions and settings. Firefox is a third-party browser, not part of Windows.
>
> **SOC NOTE**: High forensic value: `places.sqlite` (history/downloads), `cookies.sqlite`, `formhistory.sqlite`, `sessionstore-backups`, and `logins.json` + `key4.db` (saved passwords). Infostealers target these files (MITRE ATT&CK T1555.003 Credentials from Web Browsers, T1539 Steal Web Session Cookie); unexpected processes reading them are suspicious.
