**fullpath**:C:\Users\<username>\.ssh

# description

Per-user OpenSSH folder in the user's profile, used by the in-box OpenSSH for Windows client and server. It holds the user's key pairs generated with ssh-keygen and, on a server, the authorized_keys file for key-based authentication of standard users. Related tools: ssh, ssh-keygen, ssh-agent, ssh-add, scp, sftp.

## simple description

> ### 2026-11-21 Claude said
> This folder holds a user's SSH keys and settings. Private keys (id_ed25519, id_rsa, id_ecdsa) let the user log in to other servers; authorized_keys lists public keys allowed to log in to this machine as that user; known_hosts records servers the user has connected to.
>
> **SOC NOTE**: Adding a key to authorized_keys is a persistence technique (T1098.004 SSH Authorized Keys); stealing private keys enables lateral movement (T1552.004). known_hosts reveals SSH destinations. Note administrators use C:\ProgramData\ssh\administrators_authorized_keys instead.
>

# purpose

Default location for per-user OpenSSH keys. The sshd AuthorizedKeysFile default is `.ssh/authorized_keys`, resolved relative to the user's home directory (C:\Users\username); for members of the administrators group, %programdata%/ssh/administrators_authorized_keys is used instead. Learn lists C:\Users\<UserName>\.ssh\authorized_keys as the per-user keys file to back up before upgrading OpenSSH.

# common files found

| file | description |
| --- | --- |
| `authorized_keys` | Public keys allowed to authenticate as this standard (non-admin) user to the OpenSSH server. |
| `id_ecdsa` / `id_ecdsa.pub` | User key pair created with ssh-keygen; the .pub file is the public key copied to servers. |
