**fullpath**:HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e96b-e325-11ce-bfc1-08002be10318}

# description

The class registry key for the Keyboard device setup class (Class = Keyboard, GUID 4d36e96b-e325-11ce-bfc1-08002be10318), which includes all keyboards, including enumerated child HID keyboard devices. Class-wide settings such as class filter drivers are stored here; Kbdclass is the system class driver for keyboards and Kbfiltr is a sample upper filter.

## simple description

> ### 2026-11-21 Claude said
> This key holds configuration for the "Keyboard" device class: every keyboard installed on the machine is registered under it, with numbered subkeys (0000, 0001, ...) for each driver instance. The UpperFilters value lists filter drivers that sit above the keyboard class driver, normally just kbdclass.
>
> **SOC NOTE**: Kernel keyloggers and some rootkits install themselves by adding a driver to UpperFilters here (T1056.001 Keylogging, T1547 persistence via drivers). Anything other than `kbdclass` in UpperFilters (excluding known vendor drivers) deserves review; check the matching Services key and driver signature.
>

# purpose

Stores device setup class properties for keyboards, including class filter driver lists set when a class filter driver is installed.
