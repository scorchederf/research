## simple description

> ### 2026-11-21 Claude said
> WinProj.exe is the main program of Microsoft Project, the project-scheduling application. The Office14 folder means this is Project 2010 (32-bit, installed under Program Files (x86) on 64-bit Windows). It opens .mpp project files and can connect to Project Server. Project 2010 is long out of support (ended October 2020).
>
> **SOC NOTE**: Low abuse profile, but like other Office apps it runs VBA macros stored in .mpp files and can be the parent of malicious child processes after a user opens a weaponised project file (T1204.002, T1059.005). An end-of-life Office 2010 install is unpatched attack surface; flag for removal. Unusual children (cmd, powershell, rundll32) of WinProj.exe merit investigation.
