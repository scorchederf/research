## simple description

> ### 2026-11-21 Claude said
> msedge_proxy.exe is a small launcher that ships with Microsoft Edge. Shortcuts for installed Progressive Web Apps (PWAs) and site apps point to it with arguments such as --profile-directory and --app-id, and it starts msedge.exe to open that app in its own window. Seeing it in Start menu or taskbar shortcuts is normal.
>
> **SOC NOTE**: Legitimate only in the Edge Application folder and signed by Microsoft; copies downloaded elsewhere are suspicious. Its --app-id arguments reveal which PWAs a user installed. Like msedge.exe it can launch arbitrary URLs, so check command lines for unusual --app or URL arguments used for phishing or proxy execution (T1218).
