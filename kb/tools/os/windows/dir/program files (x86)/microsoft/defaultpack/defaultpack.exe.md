> DefaultPack.exe is a Microsoft component delivered with certain installers (such as Bing/MSN defaults offers) that sets browser defaults like home page or search provider. It is not a core Windows file. It typically runs once during or after installation of another Microsoft product.
>
> **SOC NOTE**: Low inherent risk, but verify the Microsoft signature and path; unsigned binaries named DefaultPack.exe elsewhere may be masquerading (T1036.005). Changes to browser home page/search provider around its execution are expected.
