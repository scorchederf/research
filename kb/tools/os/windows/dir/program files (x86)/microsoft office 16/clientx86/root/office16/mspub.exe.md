## simple description

> ### 2026-11-21 Claude said
> MSPUB.exe is Microsoft Publisher, the desktop publishing app in Microsoft 365/Office used to create flyers, newsletters and brochures (.pub files). This path is the 32-bit Click-to-Run Office installation. Microsoft has announced Publisher is retired from Microsoft 365 after October 2026.
>
> **SOC NOTE**: Malicious .pub files with macros or embedded objects have been used for initial access (T1566.001, T1204.002); MSPUB.exe spawning cmd, powershell or rundll32 is a strong indicator. ASR rules blocking Office child processes cover Publisher. Check Office trust records and recent files for opened .pub documents.
