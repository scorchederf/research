## simple description

> ### 2026-11-21 Claude said
> VSIISExeLauncher.exe is a Visual Studio 2019 Web Tools helper used when debugging ASP.NET Core apps under IIS or IIS Express. Visual Studio uses it to start the target process with the right environment and report the process ID so the debugger can attach. It is only present on developer machines with the web development workload.
>
> **SOC NOTE**: Documented LOLBin (MITRE ATT&CK T1218): `VSIISExeLauncher.exe -p <exe> -a <args>` launches an arbitrary executable through a signed Microsoft binary. Outside Visual Studio debugging sessions (parent devenv.exe), its execution is suspicious.
