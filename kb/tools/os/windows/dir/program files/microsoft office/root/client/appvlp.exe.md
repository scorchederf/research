## simple description

> ### 2026-11-21 Claude said
> AppVLP.exe is the App-V "launcher" shipped with Click-to-Run Office. It starts a program inside the Office virtual application environment so it can see Office's virtualized files and registry. Users never run it directly; Office uses it internally.
>
> **SOC NOTE**: Listed LOLBAS binary: `appvlp.exe <command>` proxies execution of arbitrary programs/scripts under a Microsoft-signed parent, helping bypass application control (MITRE T1218). Alert on appvlp.exe spawning cmd, powershell, rundll32 or binaries outside Office.
