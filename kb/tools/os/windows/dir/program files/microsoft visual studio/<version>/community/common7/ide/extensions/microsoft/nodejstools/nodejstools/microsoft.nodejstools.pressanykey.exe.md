## simple description

> ### 2026-11-21 Claude said
> A small helper shipped with Node.js Tools for Visual Studio (the Node.js development workload). When you run a Node.js app from Visual Studio, it launches node.exe and then waits for a key press so the console window stays open and you can read the output. It is a legitimate developer tool, usually started by devenv.exe.
>
> **SOC NOTE**: It spawns arbitrary child processes (node.exe with a script), so it can act as a proxy launcher; a parent other than devenv.exe, execution on non-developer hosts, or child processes other than node.exe are suspicious. Check signature and path (should be under Visual Studio's Extensions folder).
