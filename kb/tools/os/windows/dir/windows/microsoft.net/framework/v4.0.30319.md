**fullpath**:C:\Windows\Microsoft.NET\Framework\v4.0.30319

# description

This is the 32-bit installation folder of the .NET Framework 4.x runtime (Framework64 holds the 64-bit equivalent). It contains the built-in Framework DLLs for all .NET 4.x versions (4.5 and later replace 4.0 in place) and the Config folder with machine.config and the root web.config.

Every .NET 4.5-4.8.1 version installs into this same v4.0.30319 folder. The Config subfolder sets machine-wide .NET and ASP.NET defaults.

> **SOC NOTE**: Many signed binaries here are LOLBins: MSBuild.exe (T1127.001), InstallUtil.exe (T1218.004), RegAsm/RegSvcs (T1218.009), csc.exe for on-the-fly compilation (T1027.004). # purpose

Location of the built-in .NET Framework 4.x (32-bit) assemblies that the .NET loader uses; v2.0.50727 holds .NET 2.0/3.0/3.5. For .NET Framework 4 assemblies the global assembly cache moved to `%WINDIR%\Microsoft.Net` (assembly folder). Machine.config holds machine-wide .NET Framework settings at `%windir%\Microsoft.NET\Framework\<version>\Config\Machine.config`, with the root web.config next to it. Registry settings for this version live under `HKLM\SOFTWARE\Microsoft\.NETFramework\v4.0.30319` (for example AssemblyFoldersEx).

# common files found

| file | description |
| --- | --- |
| `Config\machine.config` | Machine-wide .NET Framework settings inherited by all other .NET configuration files. |
| `Config\web.config` | Root web.config with global ASP.NET settings. |
| `System.Data.dll` and other Framework DLLs | Built-in .NET Framework 4.x assemblies used by the .NET loader. |
