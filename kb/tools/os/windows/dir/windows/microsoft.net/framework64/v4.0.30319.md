**fullpath**: C:\Windows\Microsoft.NET\Framework64\v4.0.30319

# description

Installation directory of the 64-bit .NET Framework 4.x common language runtime and its built-in Framework DLLs. `C:\Windows\Microsoft.NET\Framework64` holds 64-bit assemblies (the 32-bit equivalents live under `Framework`), and `v4.0.30319` is the folder used by .NET Framework 4 and all its point releases (4.5 through 4.8.x), whose CLR version string is `v4.0.30319`. The install path can be read from the `InstallPath` entry in `HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full`.

## simple description

> ### 2026-11-21 Claude said
> This folder is the home of the 64-bit .NET Framework 4.x runtime that comes with Windows. It contains the runtime DLLs (clr.dll, mscorlib.dll, System.*.dll), compilers (csc.exe, vbc.exe, jsc.exe), MSBuild.exe and admin tools such as InstallUtil.exe, RegAsm.exe, RegSvcs.exe, ngen.exe and aspnet_regiis.exe, plus machine-wide configuration under Config\ (machine.config, web.config). Every .NET Framework 4.x version installs in place into this same folder.
>
> **SOC NOTE**: Many signed binaries here are well-known LOLBins: MSBuild.exe (T1127.001), InstallUtil.exe (T1218.004), RegAsm/RegSvcs (T1218.009), csc.exe for on-the-fly compilation (T1027.004) and AddInProcess.exe. Alert on these launched by Office, script hosts or from unusual parents, and on writes to Config\machine.config / web.config (e.g. AppDomainManager or module injection). Prefetch and Amcache entries for these binaries are useful evidence.
>

# purpose

Holds the built-in .NET Framework 4.x DLLs for 64-bit processes; the .NET loader almost always finds built-in .NET data providers in `Framework64` (64-bit) or `Framework` (32-bit), under a version folder such as `v2.0.50727` (.NET 2.0/3.0/3.5) or `v4.0.30319` (.NET 4.x). Note that for .NET Framework 4 the global assembly cache moved to `%WINDIR%\Microsoft.Net\assembly`, so shared assemblies are not stored in this folder.

# common files found

| file | description |
| --- | --- |
| `InstallUtil.exe` | Installer tool; the 64-bit CLR ships both 32-bit and 64-bit versions. Running it writes `InstallUtil.InstallLog`, `<assembly>.InstallLog` and `<assembly>.InstallState` into the assembly's directory. |
| `ngen.exe` | Native Image Generator; on 64-bit computers the scheduled task "NET Framework NGEN v4.0.30319 64" maintains native images for this architecture. |
