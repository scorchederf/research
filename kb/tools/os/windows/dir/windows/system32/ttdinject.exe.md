## simple description

> ### 2026-11-21 Claude said
> TTDInject.exe is part of Time Travel Debugging (TTD), Microsoft's record-and-replay debugging technology. It injects the TTD recorder into a target process so execution can be captured to a trace file for replay in WinDbg. On some Windows builds it ships in System32 alongside tttracer.exe.
>
> **SOC NOTE**: Listed in LOLBAS: ttdinject.exe can launch or inject into a process, providing signed-binary proxy execution (MITRE ATT&CK T1127 / T1218). TTD traces capture full process memory and may contain secrets. Any execution outside developer debugging sessions should be investigated.
