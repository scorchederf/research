**fullpath**:C:\Windows\System32\spool\drivers\x64\3

# description

The x64 version-3 printer driver directory used by the print spooler. Printer driver files are copied to the directory returned by `GetPrinterDriverDirectory` (INF dirid 66000) before the spooler's `AddPrinterDriverEx` installs them.

## simple description

> ### 2026-11-21 Claude said
> This is where the Print Spooler keeps installed 64-bit (type 3, user-mode) printer driver files such as rendering DLLs, UI DLLs and GPD/PPD data files. When a printer is added, its driver files are copied here from the Driver Store. Point and Print clients also download drivers from print servers into this folder.
>
> **SOC NOTE**: Key location for PrintNightmare (CVE-2021-34527/1675) and similar spooler exploits: malicious DLLs dropped here (often in numbered subfolders like 3\4 or 3\New/Old) load into spoolsv.exe as SYSTEM (T1068, T1547.012 Print Processors / T1574). Look for recently created unsigned DLLs, and events in Microsoft-Windows-PrintService/Admin and Operational (e.g. 316, 808).
>

# purpose

Holds printer driver and dependent files for the native x64 architecture. All driver files must be located in the `GetPrinterDriverDirectory` path when the printer class installer calls `AddPrinterDriverEx`.

# common files found

| file | description |
| --- | --- |
| `amd64\tty.gpd` | Generic/text-only (TTY) printer GPD file. |
| `amd64\tty.ini` | TTY printer driver INI file. |
| `amd64\ttyres.dll` | TTY printer driver resource DLL. |
| `amd64\ttyui.dll` | TTY printer driver UI DLL. |
| `amd64\ttyui.hlp` | TTY printer driver help file. |
