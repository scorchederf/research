**fullpath**:C:\Windows\System32\spool\drivers\W32X86\3

# description

This folder is part of the print spooler's printer driver store for x86 (32-bit) drivers, under `system32\spool\drivers\w32x86`. The `3` subfolder holds version 3 printer driver files, such as vendor driver DLLs. Driver files must be in the directory returned by the spooler's `GetPrinterDriverDirectory` function (INF dirid 66000).

## simple description

> ### 2026-11-21 Claude said
> This folder stores 32-bit (x86) printer driver files that the Windows Print Spooler uses. The "3" means these are version 3 (user-mode) drivers. On 64-bit systems it mainly holds drivers that the server shares with 32-bit clients through Point and Print. Files land here when a printer driver is installed.
>
> **SOC NOTE**: The spooler driver folders were central to PrintNightmare (CVE-2021-34527/CVE-2021-1675), where attackers dropped malicious DLLs that spoolsv.exe loaded as SYSTEM (MITRE ATT&CK T1068, T1547.012 Print Processors/monitors). Check for recently created or unsigned DLLs here and in the x64 `3` folder, review the PrintService/Admin and Operational logs (Event ID 316, 808), and Sysmon Event ID 11 file creations by spoolsv.exe.
>

# purpose

The spooler installs printer drivers when the printer class installer calls `AddPrinterDriverEx`, which requires all driver files to be located in the directory returned by `GetPrinterDriverDirectory`. For x86 builds, the BinPlace `printer` class maps to `system32\spool\drivers\w32x86` (AMD64 uses `w32amd64`, IA64 uses `w32ia64`). Microsoft Learn shows vendor driver DLLs such as an HP `Hpzpi4wm.dll` stored in `C:\WINDOWS\system32\spool\drivers\w32x86\3`.
