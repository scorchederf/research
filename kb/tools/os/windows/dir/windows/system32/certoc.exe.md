> ### 2026-11-21 Claude said
> CertOC.exe is a certificate utility found mainly on Windows Server, used to install and manage certificates and certificate stores from the command line.
> It is a lightweight relative of certutil and is not present on all client editions.
>
> **SOC NOTE**: LOLBAS entry: `certoc.exe -LoadDLL <dll>` loads an arbitrary DLL (T1218 proxy execution) and `-GetCACAPS <url>` can download text/scripts (T1105). Any execution outside PKI administration should be investigated.
