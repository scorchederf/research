## simple description

> ### 2026-11-21 Claude said
> Update.exe is the Squirrel-based installer/updater for the per-user classic Microsoft Teams desktop client. It installs, updates and launches Teams from the user profile without admin rights. Classic Teams is retired, so this file mostly appears on older or not-yet-cleaned machines.
>
> **SOC NOTE**: Known LOLBin (LOLBAS): `Update.exe --processStart`, `--update` or `--download` can download or execute arbitrary binaries (T1218, T1105), and malware has replaced files in the Teams folder for persistence. Investigate unusual command lines or child processes, and network downloads by update.exe.
