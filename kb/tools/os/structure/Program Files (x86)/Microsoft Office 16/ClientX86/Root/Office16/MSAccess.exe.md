## simple description

> ### 2026-11-21 Claude said
> MSAccess.exe is Microsoft Access, the Office database application used to build small databases, forms and reports. This path is the 32-bit version installed by Microsoft 365 / Office Click-to-Run. Access opens database files such as `.accdb`, `.mdb`, `.accde` and `.mde`, and those files can contain macros and VBA code. It's mostly used by business users and small line-of-business apps.
>
> **SOC NOTE**: Access database files are an occasional phishing attachment format: macros (including an `AutoExec` macro) and VBA can run code when the file is opened (MITRE ATT&CK T1566.001, T1204.002). Watch for MSAccess.exe spawning cmd.exe, powershell.exe or other script hosts, or making unexpected network connections, and check Office macro security settings and Trusted Locations.
